# Doorplate Meta

台灣門牌符號練習網站。先把門牌符號與地區整理成圖鑑，再用純圖像題目練習辨認鄉鎮市區。

## 開發

使用 Node.js 24（本次驗證版本 24.19.0）與 npm。

```sh
cd /workspace/DoorplateMeta
npm ci --cache /tmp/doorplate-npm-cache --no-audit --no-fund
npm run dev
```

開發伺服器監聽 `0.0.0.0:5173`。不需要 API 金鑰、後端服務或資料庫伺服器。正式版可部署 `npm run build` 產生的 `dist/` 靜態檔案，請使用固定的 HTTPS 網址以保留相同瀏覽器儲存空間。

## 部署到 Netlify

1. 登入 Netlify，選擇 **Add new project → Import an existing project → GitHub**。
2. 授權 Netlify 存取 `WESLEY-CHEN-05/DoorplateMeta`，選取該儲存庫與 `main` 分支。
3. Base directory 留空；Build command 使用 `npm run build`；Publish directory 使用 `dist`。儲存庫的 `netlify.toml` 已保存這些設定與 Node.js 版本。
4. 選擇部署。成功後 Netlify 會提供公開 HTTPS 網址；以後推送到 `main` 會自動重新部署。

不需新增環境變數或付費網域。GitHub 的 **Download ZIP** 下載的是原始碼，不能把它當成已建置網站直接拖進 Netlify Drop；請使用上述連接儲存庫的方式。每位訪客的自訂題庫與練習紀錄只存在自己的瀏覽器。

## 功能

- **符號建題**：匯入 PNG、JPG 或 WebP，拖曳裁切或輸入百分比，只保存裁出的符號；可以在同一張對照表上連續建題。
- **地區對照**：22 縣市、368 鄉鎮市區選單；圖鑑支援搜尋、縣市篩選、格狀和列表檢視。
- **練習模式**：完整符號、輕度模糊、左半裁切、縣市篩選、洗牌、查看答案與跳題。
- **答案判定**：接受鄉鎮市區全名，或「縣市＋鄉鎮市區」；接受台／臺、空白與常見分隔標點差異。必須包含鄉／鎮／市／區後綴，不接受部分名稱、錯誤縣市或模糊比對。
- **錯題複習**：答錯或查看答案會進入錯題清單，後續答對移出。查看答案計入作答但不算答對，跳題不計分。
- **本機保存**：圖片與練習紀錄存於 IndexedDB；重新整理不會遺失。可匯出 JSON 題庫（含圖片、答案、筆記與來源），不包含練習紀錄。
- **批次匯入**：JSON 先驗證整份資料、預覽與人工確認再一次寫入；拒絕外部圖片網址、SVG、無效地區、損壞圖片，並略過重複符號。

## 目前的資料狀態

已依使用者直接提供的 life.cq「宜蘭縣門牌」圖片，逐項整理出 **宜蘭縣全部 12 個鄉鎮市** 的圖案對應與辨識重點；打開網站即載入預設題庫，不必先手動建題。[查看完整對照表](CATALOG.md)。

**內建圖片是 AI 依參考圖重製，非原圖裁切或實拍照片。** 生成後依格位擷取為獨立 PNG，完全不含地名與文字；細部線條、比例、色彩或人物姿勢可能與原圖不同。畫面、筆記及匯出題庫都保留重製標示。適合先練習主題與地區配對，不能宣稱為逐像素忠實的原圖資料。

參考貼文是 [life.cq 的 Threads 整理](https://www.threads.com/@life.cq/post/Dbw2vlYj61J)。雲端環境直接存取 Threads 曾遭 proxy 403 拒絕；本次對應資料來自使用者上傳圖，並未成功擷取整篇貼文。

網站提供明確標示的單題人造示範，用於試用輸入及難度切換。示範的「示範縣／示範區」沒有真實地理對應，也不會寫入正式題庫或紀錄。自動測試的圖片與地區配對也僅為測試資料，沒有隨網站發佈。

可在「資料管理 → 新增門牌符號」匯入原始照片，裁出無文字符號，填寫地區與來源，核對後儲存。同一地區可有多種門牌樣式。圖案不一定與地區一對一；若同一符號跨區使用，應在整理資料時查證並補充筆記，目前每筆題目對應一個地區。

預設題庫採一次性初始化，不覆寫自訂題目與作答紀錄，刪除預設題後重新整理也不會自動加回。會自動升級先前版本的 IndexedDB 並保留既有資料。

裁切工具不會自動 OCR；需要人工確認圖案不含地名、數字及文字。正式題目不會以檔名、alt 或標題洩漏答案；答案、筆記與來源連結只在作答或揭曉後顯示。

地區名稱的資料來源與篩選記錄見 [SOURCES.md](SOURCES.md)。

## 驗證

```sh
npm run build
npm test
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

瀏覽器測試預設使用 Playwright Chromium；環境已有 Chromium 時，用 `CHROMIUM_PATH` 指定可執行檔。沒有安裝瀏覽器的機器可先執行 `npx playwright install chromium`。測試會啟動或重用 5173 的開發服務。

瀏覽器測試使用獨立暫存的瀏覽器 context，不會修改使用者的題庫；覆蓋裁切輸出像素、答案隱藏、判定、錯題、鍵盤操作、重新整理保存、匯入驗證、去重、匯出、刪除、紀錄重設與手機寬度。

## JSON 題庫格式

```json
{
  "version": 1,
  "questions": [
    {
      "county": "臺南市",
      "district": "永康區",
      "image": "data:image/png;base64,（裁切圖片的 base64；此處僅為格式示意）",
      "source": "https://來源網址",
      "note": "作答後顯示的辨識筆記"
    }
  ]
}
```

單次檔案限 25 MB、1–500 題；每張裁圖限 1,500,000 字元且各邊 16–2048 像素。建題工具會把圖片最長邊縮至 640 像素。匯入時不信任外部 ID，會重新產生 ID，避免覆蓋現有題目或紀錄。上述範例只有格式用途，不是真實門牌資料，也不是可直接匯入的有效圖片。

沒有帳號或雲端同步；不同裝置、瀏覽器、網域、協定、port 各自儲存。清除瀏覽器網站資料也會清除題庫，請定期匯出備份。
